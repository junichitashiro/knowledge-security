# セキュリティ対策導入ガイドライン

中小企業がセキュリティ対策をゼロから始める場合のガイドライン

## 1. 全体の方針を決める（セキュリティポリシー策定）

### 目的と基本方針を明確にする
- 何を守るのか（情報資産の特定）
- どのレベルのセキュリティを目指すのか
- 誰が責任者になるのか

### セキュリティルールの策定
- 従業員が守るべき基本ルール（パスワード管理、アクセス制御など）
- 外部とのデータのやり取りのルール（USB使用禁止、メール添付制限など）

## 2. 現状のリスクを把握する（アセスメント）

### IT資産の棚卸し
- 社内のPC、サーバー、ネットワーク機器、クラウドサービスの把握
- どの情報（顧客情報、設計データなど）がどこにあるか特定

### リスク分析
- データの流れを確認し、漏洩や不正アクセスのリスクを特定
- 従業員のセキュリティ意識や対策レベルを把握

## 3. 最低限の技術的な対策を実施する

### 基本的なセキュリティ対策
- OS、ソフトウェアの更新を徹底（Windows Update、セキュリティパッチ適用）
- アンチウイルスソフト導入（EDRの導入も検討）
- ファイアウォールの設定（不要なポートを閉じる）
- アクセス権限の適正化（不要な管理者権限を削除）
- バックアップの実施（重要データを定期的にバックアップし、復元テストを行う）

## 4. 従業員へのセキュリティ教育を実施する

### 最低限の教育内容
- フィッシングメールの見分け方
- パスワードの適切な管理（多要素認証の活用）
- 機密情報の取り扱いルール
- 不審な動きがあった場合の報告フロー

## 5. インシデント対応計画を策定する

### 対応の流れを事前に決めておく
- ウイルス感染や情報漏洩が発生した場合の連絡先
- 初動対応の手順（端末隔離、ログ取得 など）
- 社内外への報告ルール（必要に応じて警察やIPAへの通報）

## 6. 継続的な見直しと改善

### 定期的な見直しを実施
- 年に1回はリスクアセスメントを実施
- 外部のセキュリティサービスや専門家の活用も検討
